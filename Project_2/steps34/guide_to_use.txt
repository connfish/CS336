## Steps 3 & 4 (Alexandra Domanski)

### To Setup
1. Go to the steps12 folder and activate the virtual environment:
   cd Project_2/steps12
   source llm_env/bin/activate

2. Go to steps34 folder:
   cd ../steps34

### How to Run
3. Run the script:
   python3 text_process.py

4. The model will take a bit to load, then it will prompt:
   Enter a question or type 'exit' to close:

5. Type a question using natural language about the NJ HMDA 2017 database, for example:
   - How many mortgages have a loan value greater than the applicant income?

6. In the terminal, there will be outputted a SQL query generated by the LLM.

7. Type 'exit' to quit.

### Files to use
- text_process.py - main script
- subset.sql - database schema fed to the LLM
